怎么用这张书桌

  1. 古籍总目：按书名、作者、朝代或四部检索 9,000 余部 Kanripo 书目，点开可跳转原库。
  2. 全文检索：勾选核心史籍，在浏览器内检索正文；结果可展开上下文，不上传检索词。
  3. 人物检索：输入姓名或 CBDB ID，直接读取 CBDB 的 JSON 接口。
  4. 史料摘录：阅读人工校读的族源与地理条目，并可回到对应年份的疆域图。

数据边界：书目为 Kanripo 仓库元数据；全文为公版古籍整理本，仅供个人研究；CBETA 限非商业使用；CBDB 与 CHGIS 的引用请遵循各自条款。文中按语为本站整理，不替代原始研究。
