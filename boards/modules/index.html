新增一个子板块

子板块不写进内核，也不由生成器改写。三步即可挂上一个新单元：

  1. 新建目录 boards/<id>/，放入自包含的 index.html 与 board.json。
  2. 在 boards/registry.json 的 boards 中登记，group 填 "modules"。
  3. 刷新页面：顶部导航与这个总览页会自动出现新单元。
{
  "id": "your-unit",
  "title": "你的子板块",
  "description": "一句话说明",
  "group": "modules",
  "path": "boards/your-unit/",
  "entry": "boards/your-unit/index.html",
  "order": 50,
  "context": [],
  "status": "active"
}

约定：目录自包含；不引入 core/ 也能打开；生成器不改写板块页；校验器只查契约。完整说明见 docs/ARCHITECTURE.md。
